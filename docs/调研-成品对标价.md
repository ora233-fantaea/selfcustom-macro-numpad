## 最接近自制款的三个

1. **佐亚 GMK26（¥166~189）**：26 键 + 旋钮、QMK/VIA、热插拔、Gasket + 4 层吸音棉、塑料壳——键数与旋钮位置几乎就是自制款的翻版，只差"3D 打印壳"与"RP2040 主控"。比自制物料（¥170~330）基本持平；比自制首单（¥350~500 当时口径）便宜 ¥160~330。
2. **Keychron Q0 Plus（国行 358 / 现官网 ≈648）**：26 键 + 左旋钮 + QMK/VIA + 热插拔，外壳 CNC 铝、主控 STM32。国行 358 时与自制首单下限打平。
3. **菜籽猫 DS21 ENCODER（¥129.99）**：3D 打印壳 + 旋钮 + QMK/VIA + 热插拔，形态上最像"别人把自制款做成了商品"，但只有 21 键、有线单模。

## 最便宜能满足核心需求（旋钮 + 可编程）

- **要 QMK/VIA + 旋钮 + 热插拔**：菜籽猫 DS21 ¥129.99 最低；要 26 键完整数字区则 GMK26 ¥166 最低。
- **只要"旋钮 + 能改键"、不在乎开源固件**：凯酷 K19 / 珂芝 K20 各 ¥129（自研驱动，掉电保存，但换不了固件、层数少）。
- 真正的价格地板：雷柏 K10 ¥39、双飞燕 TK-5 ¥39——薄膜不可编程，仅用于说明"最便宜能买到什么"。

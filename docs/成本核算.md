## 三个反直觉的发现

**1）成本大头不是打板，是零配件和外壳。**
打板只占 ¥60、贴片加工只占 ¥80；真金白银花在轴、键帽、棉、外壳、运费这些"零售价"上。厂家按批发价买，你按零售价买，这笔差价补不回来。

**2）MCU 自己焊省不到钱。**
SMT 加工费只有 ¥80（工程费 ¥50 摊在 5 片上），自己焊要买钢网 ¥55~71 + 锡膏，净省 **¥10~30**，却要多花 4~8 小时，且 QFN-56（0.4 mm 脚距 + 底部散热盘）有实打实的失败风险——虚焊时你分不清是焊坏了还是固件不对。

**3）"只贴 MCU 区、其余手焊"是最差选项。**
全贴 ¥80、只贴 MCU 区 ¥77，差 **¥5**，但后者要自己焊掉 108 个焊点（26 轴座 + 27 二极管 + 2 短接盘）。要么全贴，要么全手焊。

## 没进表里的三笔钱

| 项 | 金额 | 说明 |
|---|---|---|
| 工具（若没有） | ¥185~255 | 烙铁 ¥80~150 + 焊锡助焊 ¥40 + 镊子 ¥15 + 万用表 ¥50；自己焊 QFN 再加热风枪 ¥150~250 |
| 工时 | 8~15 h | 焊接 3~5 h、棉开孔 1~2 h、QMK/Vial 编译与调试 4~8 h（棉激光开孔加 ¥30~50 可省 2 h） |
| 返工 | +¥60~120 / 次 | 一次打样改不了板；真错了要重打 + 等一周 |

## 什么时候自己做才说得过去

1. **已有工具 + 一批轴和键帽**：省 ¥185~255 工具费 + ¥40~90 轴帽钱，首单直接掉到 ¥400 附近
2. **打算做 2~3 把**（送人/备用），单价压到 ¥286~577
3. **要成品买不到的配列**：这份设计确实是——左列 5 颗宏键 + 顶排 4 颗 F 键 + 竖 2u 的 `+`/`Enter` + `0` 居中 2u + **6° 倾角** + 按口味配的消音堆叠。GMK26 与 Q0 Plus 都是水平放置、没有 F 键排
4. **把"我自己做的"本身当收益**，不计工时

这四条一条都不占，买 GMK26（¥166）或 Q0 Plus（¥358）更理性：省下的不是几百块，是 8~15 小时和返工风险。

## 编者注：卫星轴到底要几对

调研记录里有一条建议"3 对卫星轴"，与这份设计不符，这里澄清：PCB 上只有 `0` 键开了稳定器孔位（`STB1`，一对）。`+` 与 `Enter` 是 1u×2u 竖键，**设计上不装稳定器**（见 [plan.md §2.1](../plan.md)），按下去会晃但能用。所以：

- 现在买 **1 对**就够；
- 想让 `+`/`Enter` 也装稳定器，**得先改 PCB 加两组孔位**（并重打板），光买 3 对没用。

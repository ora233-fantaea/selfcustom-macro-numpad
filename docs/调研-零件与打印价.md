## 二、外壳 3D 打印

外壳为三件（FDM）：底壳 ≈107×138×12 mm、壁厚 2.4；上盖 ≈同外形高 8 mm，26 个 MX 方孔 + 旋钮凸台 + 6 沉头孔；键面 6° 倾斜、底面水平。估耗材 150~250 g（含 6° 斜面支撑，比实测重量多 10~20%）。

### 1）嘉立创 3D 打印（FDM）

- 计价：按模型**重量**（含支撑）计价，上传 STL/STEP 实时出价，1 件起订、2 元起步、无最低消费
- 材料档位：PLA-P（最低价档，12H 交期）< PLA-C 彩色 < ABS/PA12-CF/TPU < ASA/PC-ABS < PEEK。**现无 PETG**
- 每克单价：官方只给相对档位；历史价目为工程塑料（FDM）**0.7 元/克起**、树脂 0.36 元/克起、尼龙 1.4 元/克起
- 真实锚点：开源 75% 键盘 Cherish-75 作者写明"外壳用嘉立创三维猴，上壳 + 下壳 150~200 元"（约 400~450 g → **≈¥0.35~0.5/g**）
- **本件 150~250 g 推算：¥60~110（中位 ¥85）**，置信度中

### 2）淘宝/闲鱼 FDM 代打

- 按克：PLA **0.08~0.15 元/g**（个人/农场）、0.2~0.25（B 站服务商）、0.3 起（服务商）；光固化 0.8 元/g；小件起步价 ¥9.9~30
- 按件真实成交：闲鱼 PETG 65% 外壳 ¥59~79/套；拼多多/淘宝小壳 ¥30 起
- **本件 150~250 g：¥35~70**（另加邮费 ¥8~12），置信度中高

## 三、外壳打印结论

| | 方案 | 价格 | 说明 |
|---|---|---|---|
| **经济档** | 淘宝/闲鱼 FDM 代打 PLA 或 PETG | **¥35~70**（+邮费 ¥10） | PLA 约 65 ℃ 软化，**建议上 PETG**（+¥10~20） |
| **均衡档（推荐）** | 嘉立创 FDM PLA-P | **¥60~110** | 公差 ±0.3 mm、包邮，可加"镶嵌螺母"后处理省手工热熔 |
| **精致档** | 嘉立创 SLS/MJF PA12 尼龙 | **¥180~320** | 无层纹、可直接攻牙，客制化外壳的主流精致方案 |
| 精致档备选 | SLA 树脂 | ¥60~120 | 表面细腻但大平面翘曲 + 脆，不推荐做上盖 |

三条工艺提醒：6° 斜面必须加支撑（计价重量多 10~20%）；外观面用 0.12~0.16 mm 层高并朝上摆放，否则斜面层纹明显；6 个 M3 铜螺母手工热熔易偏心，嘉立创有"镶嵌螺母"后处理可加。

## 编者注：关于"3 对卫星轴"

本调研记录曾建议"26 键里有 3 个 2u 键，需 3 对卫星轴"。**与本设计不符**：PCB 上只有 `0` 键开了稳定器孔位（`STB1` 一对），`+` 与 `Enter` 是 1u×2u 竖键，设计上不装稳定器（见 [plan.md §2.1](../plan.md)）。因此当前只需 **1 对**；要让 `+`/`Enter` 也装，必须先改 PCB 加两组孔位并重打板。

同时提醒：淘宝 17/21 键数字区键帽套装**多数不含竖 2u 的 `+` 与 `Enter`**，下单前必须让卖家确认含 2u/竖 2u 增补，否则买 104 键小全套拆用。

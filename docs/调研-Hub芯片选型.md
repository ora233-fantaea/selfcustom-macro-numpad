## 2. 推荐

**SL2.1A**（C6798314）
- 4 口只用 2 口；SOP-16 好贴好返修；XIN 接 GND 即内部 12M 振荡器，**整板零晶振**。
- 内置 5V→3.3V、3.3V→1.8V，外部只需 3 颗退耦电容。
- 单价 ≈¥1.7，33k 现货。
- 代价：STT、0~70℃、手册只有 7 页（未明示内置 1.5k 上拉/15k 下拉，建议留 DNP 焊盘）。

**备选 CH334P**（C5373042，¥2.88）
- 手册明确"上行端口内置 1.5KΩ 上拉、下行端口内置 15KΩ 下拉"，MTT，-40~85℃，6kV ESD，28 页中文手册带完整参考原理图。
- 若用 CH334，**按贴 12MHz 晶振设计**（CH334/FE1.1s/FE8.1 均内置晶振负载电容，不用外挂 22pF）。

**晶振占多少面积**
- 3225 晶振：3.2×2.5 = 8.0 mm²；两颗 0402 负载电容（含焊盘间隙）≈3.5 mm² → 合计 ≈11.5 mm²，加布线/禁布 ≈15 mm²。
- 2016 晶振：3.2 mm²，+2 电容 ≈7 mm²。
- CH334/FE1.1s/FE8.1 内置负载电容 → 只占晶振本体：3225 = 8 mm²，2016 = 3.2 mm²。
- 对 100×60 mm 键盘板可忽略；真正成本是 BOM 一行 + 贴片费。

## 4. CC 电阻

- 上游 C 座（对着电脑，UFP/sink）：CC1、CC2 **各一颗 5.1 kΩ 下拉到 GND**。C-to-C 正反插都能取电（默认 500 mA 档）。不要加 56k 上拉；只接一颗是最常见错误。
- 下游 C 座（对着 M5Dial，DFP/source）：CC1、CC2 **各一颗 56 kΩ 上拉到本口 VBUS**（default 500 mA 档）。不要加 Rd。
- 板内下游口（RP2040，无连接器）：不接 CC，DP/DM 串 27 Ω 即可。
- M5Dial 的 C 口若没有 Rd，C-to-C 线不会上电 → 改用 A-to-C 线。

## 5. 已知坑

1. ESP32-S3 做 host 时 ESP-IDF 旧版不支持 hub（v5.3+ 有 CONFIG_USB_HOST_HUBS_SUPPORTED）。本项目 S3 是 device，不受影响。
2. FE8.1 恒定上报 self-powered，主机按 500 mA/口分配，实际供不出 → 掉压重启。
3. 下游无大电容 → M5Dial 开机瞬间拉流导致 hub 掉线（≥100 µF）。
4. 上游 CC 只接一颗 → C-to-C 反插不供电；下游 CC 接成 Rd → 永远不供电。
5. 下游 VBUS 直连上游且无限流 → M5Dial 外供电时倒灌进电脑。
6. CH334 免晶振是"订购确认"的配置位，市售现货默认晶振模式；XI 接地不一定生效。
7. SL2.1A 手册未明示内置 1.5k/15k，建议留 DNP 焊盘兜底。
8. 供电预算：5.1k Rd → 整机 500 mA（USB3 口 900 mA）。hub 50~85 mA + RP2040 30~50 mA + M5Dial ≈140~170 mA；M5Dial 充电时可能超。建议 M5Dial 用自身电池/后部电源端子，hub 只给数据 + 小电流。

## 6. 4 口当 2 口

可以。未用口的 D+/D- 悬空即可（内置下拉不会误判）。BOM 不增加，主机侧只是看到一个 4 口 hub、2 口空。真正的 2 口芯片（USB2512B ¥22、TUSB4020B ¥31）又贵又大还要 24MHz 晶振，完全不划算。
